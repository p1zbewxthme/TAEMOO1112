# 돌이킬 수 있을지도 모를 걸음

백석기계공업고등학교를 배경으로 한 2D 쯔꾸르식 웹 방 탈출 게임입니다.  
이 릴리스는 사용자가 제공한 《게임제작 1.txt》 및 《게임제작 2.txt》의 **강무결 시점**으로 제작했습니다.

## 실행하기

압축을 풀고 `index.html`을 브라우저에서 열거나 GitHub Pages로 배포합니다. 서버 설치나 빌드 과정은 없습니다. 각 파일의 상대 경로를 유지해 주세요.

### GitHub Pages

1. 새 GitHub 저장소를 만들거나 기존 게임 저장소를 엽니다.
2. 이 ZIP의 `index.html`, `game.js`, `styles.css`, `.nojekyll`, `assets/` 폴더를 저장소 **최상위 폴더**에 업로드합니다. 기존 파일은 새 파일로 덮어씁니다.
3. **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하고 저장합니다.
4. 배포된 `https://<계정>.github.io/<저장소>/` 주소로 접속합니다. 수정 전 화면이 남아 있다면 강력 새로고침합니다.

이미지 및 음원은 모두 `assets/` 폴더에 포함했습니다. 게임 화면의 서체는 원본 지시대로 웹 CDN의 `StoryBold`를 불러옵니다. 인터넷을 연결할 수 없는 경우에는 운영체제 대체 서체가 나타납니다.

## 플레이

- PC: 방향키 또는 **W/A/S/D**로 네 방향 이동, 조사할 사물 **마우스 클릭**. Enter/스페이스는 진행 또는 주변 조사에 사용합니다.
- 모바일: 화면 아래 방향 버튼을 길게 누르거나 사물을 터치합니다.
- 메시지: **▼ 다음**을 누르거나 **SKIP**으로 현재 대화 묶음을 건너뜁니다. 결과가 달라지는 선택지는 직접 선택해야 합니다.
- 화면 위쪽의 **소지품**으로 획득한 아이템을 확인할 수 있습니다.
- 음악: **START**를 눌러 시작할 때 BGM이 재생됩니다. 복도↔계단 전환 때는 별도 계단 효과음이 재생됩니다. 음소거 버튼이 있습니다.

## 게임 구성

1. **STAGE 1 — 너무도 길었던 꿈**: 3학년 4반의 책상·게시판·사물함을 조사하고 자물쇠를 해제합니다. 제공된 기획서의 4자리 비밀번호, 아이템, X 표시, 선택지, 첫 번째 실패 엔딩을 유지했습니다.
2. **STAGE 2 — 삼도천 혹은 스틱스 강**: 복도에서 단서를 확인하고 계단으로 이동합니다. 잘못 내려가면 두 번째 실패 엔딩입니다.
3. **STAGE 3 — 연옥에서**: 어두운 미술실 문을 소지품으로 엽니다. 열쇠 꾸러미가 없다면 **미술실 → 계단 → 복도 → 교실**을 거쳐 되돌아갈 수 있습니다. 열쇠를 얻은 후 미술실 문을 열면 창가에 기태하가 나타납니다. 기태하의 질문에 따른 선택지와 **엔딩 3·4**가 구현되어 있습니다.

### 엔딩

- 엔딩 1: 주연호의 초콜릿을 먹음
- 엔딩 2 — 무저갱: 계단 아래로 내려감
- 엔딩 3 — 네 번의 생이 주어진다면: 기태하와 대화 후 동행하여 미술실 문으로 나감
- 엔딩 4 — 갈림길: 기태하와의 대화가 어긋남

각 엔딩 이후에는 **REPLAY**로 처음부터 다시 시작합니다.

## 캐릭터와 맵

- 주인공 **강무결**: 제공받은 원본의 3열×4행 스프라이트 시트로 네 방향 이동/걷기 애니메이션 구현.
- **기태하**: 원본 시트를 분리한 3열×4행, 총 12프레임으로 창가 대기 및 동행 이동 구현. 머리·발이 잘리지 않도록 프레임을 전체 영역 기준으로 렌더링합니다.
- 제공받은 교실, 복도, 계단, 미술실 맵과 아이템 원본을 사용했습니다.
- PC에서는 가로 16:9 카메라, 모바일 세로 화면에서는 확대 추적 카메라를 적용했습니다. 이미지 자체를 가로로 늘리지는 않습니다.

## 구현 및 테스트

- 정적 HTML5 Canvas + CSS + JavaScript. 프레임워크·빌드 종속성 없음.
- 벽/가구 충돌, 클릭 이동의 경로 탐색, 맵 전환, 상태/소지품 관리, 사물함 개별 조사, 퍼즐, 분기 대화, NPC 동행, 엔딩/재시작 구현.
- **브라우저 자동 테스트**: PC 및 모바일 화면 크기에서 미술실 잠금 해제, 기태하 등장/대화, 동행 이동, 엔딩 3/4, 원래 맵으로 되돌아가기 및 열쇠 재획득, 담배 아이템 이미지 표시를 확인했습니다.
- **경로 테스트**: 미술실 입구에서 기태하에게 이동하고, 기태하와 함께 출입문까지 돌아오는 자동 이동 경로 확인.
- 실제 사용자의 개별 모바일 기종과 브라우저에서는 추가 테스트가 필요합니다.

## 유의사항

사용자가 제공한 이미지·음악·텍스트를 기반으로 제작했습니다. GitHub에 공개 배포하기 전 각 자료의 공개 이용 권한을 확인해 주세요. 브라우저는 사용자 입력 이전의 자동 오디오 재생을 제한할 수 있으므로 **START** 버튼에서 음악을 시작하도록 설계했습니다.
