# 돌이킬 수 있을지도 모를 걸음 — 웹게임 PART 01

제공된 `게임제작 1.txt` 기획서와 이미지·오디오 리소스를 토대로 제작한 **HTML5 Canvas 기반 쯔꾸르형 탈출 게임 PART 01**입니다. RPG Maker 프로젝트 파일이 아닌, RPG Maker 방식의 맵 탐색과 선택지 시스템을 브라우저에서 구현한 웹게임입니다. 외부 게임 엔진이나 빌드 과정이 필요 없습니다.

## 실행 방법

압축을 풀고 `index.html`을 브라우저에서 열어 게임을 시작할 수 있습니다. 일반적인 웹 서버 또는 GitHub Pages 환경에서도 그대로 동작합니다.

### GitHub Pages 배포

1. GitHub에서 저장소를 만들거나 사용할 저장소를 엽니다.
2. 이 ZIP을 압축 해제한 **내부 파일 전체**(`index.html`, `game.js`, `styles.css`, `assets/` 등)를 저장소 최상위 경로에 업로드하고 `main` 브랜치에 커밋합니다. ZIP 파일만 올리면 안 됩니다.
3. GitHub 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치를 `main`, 폴더를 `/(root)`로 설정하고 저장합니다.
5. GitHub Pages가 표시하는 공개 URL을 통해 플레이합니다.

> 음원은 브라우저 자동재생 정책에 따라, 사용자가 **START**를 클릭하는 순간 자동으로 재생됩니다. 화면 진입만으로 클릭 없이 음악을 재생하도록 강제할 수는 없습니다.
>
> StoryBold 폰트는 기획서에서 지정한 외부 CDN을 통해 로드되므로 인터넷 연결이 필요합니다. 폰트 연결에 실패하면 시스템 대체 폰트가 표시됩니다.

## 조작

- **방향키 / WASD:** 상하좌우 이동. 대각선 이동 없음. 교실에서 탐색 메뉴가 열려 있어도 방향키를 누르면 메뉴가 닫히고 바로 이동합니다.
- **마우스 클릭:** 사물이나 바닥을 클릭하면 경로를 찾아 이동하거나 조사합니다.
- **스페이스바:** 가까운 사물을 조사합니다.
- **▼ / Enter:** 대화 넘기기.
- **SKIP:** 현재 대사 묶음을 넘기기. 분기 선택지는 자동 선택하지 않습니다.
- **숫자 키 1~9:** 선택지 선택.
- **Esc:** 일부 대화·메뉴 닫기. 계단에서는 이동 모드로 돌아갑니다. 교실의 탐색 선택지는 방향키로 바로 닫고 이동할 수도 있습니다.
- **소지품:** 우측 상단 아이콘에서 획득한 물품 확인.
- **F2:** 개발용 충돌/상호작용 구역 표시 토글.
- **모바일:** 게임 화면 아래 방향 패드와 조사 버튼 이용.
- **정지와 걷기 애니메이션:** 원본 스프라이트의 네 방향·각 3프레임을 각각 정렬해 사용합니다. 이동하지 않을 때는 정지 프레임을 표시합니다.

## 기획서 1 구현 범위

| 구역 | 구현 내용 |
|---|---|
| 교실 | 암전 도입, 강무결 자리 조명, 초기 독백과 선택지, 조사 메뉴, 책상·성서·서랍, 게시판, 휴지통, 36개 사물함, 조건부 자물쇠 그래픽, 비밀번호 `3437`에 따른 탈출 |
| 복도 | 3-4반 출석부와 교실 문 상호작용, 분리수거함의 빈 물병, 계단으로 이동 |
| 계단 | 위/아래 선택, 하강 시 실패 엔딩, 올라갈 때 미술실 진입, 복도 복귀 |
| 미술실 | 제공 맵 표시와 기본 이동·충돌 판정, 계단 복귀. 다음 기획서를 위한 빈 스테이지 |
| 공통 | 방향별 캐릭터 걷기, 장애물 통과 금지, 클릭 지점까지 자동 이동, 모든 대화의 ▼ 및 SKIP, 아이템 창, BGM, 계단 효과음, REPLAY |

### 사물함 퍼즐 주의사항

- 이미 조사한 사물함에는 붉은 X 표시를 합니다. **명예희 사물함은 예외**입니다.
- 임은재 사물함만 조사하면 자물쇠에 `參死` 단서가 나타납니다.
- 명그린 사물함만 조사하면 자물쇠에 `全員` 단서가 나타납니다.
- 둘 다 조사하면 완전한 단서가 있는 자물쇠 이미지가 나타납니다.
- 주연호 사물함의 초콜릿을 먹으면 **엔딩 1**, 계단에서 아래로 내려가면 **엔딩 2 — 무저갱**으로 진행합니다.

## 미술실 PART 02 개발 시

`game.js`에서 다음 위치를 이어서 수정하면 됩니다.

- `ascendStairs()` — 미술실에 진입한 다음 스토리 시작 지점.
- `MAP_INFO.artroom` — 미술실 충돌 판정 사각형.
- `hotspots()` — 미술실의 클릭 가능한 오브젝트 목록.
- `S.inventory` — 교실·복도에서 획득한 아이템 상태. 미술실에서도 유지됩니다.
- `pages()`, `choices()`, `endingScreen()` — 대사/선택지/엔딩에 재사용할 함수.

이 버전의 플레이어는 《게임제작 1.txt》에 명시된 **강무결**입니다. 과거 구상에 있던 기태하 선택 루트는 이 기획서에 없으므로 아직 추가하지 않았습니다.

## 파일 구조

```text
index.html                 게임 시작 파일

assets/maps/               교실·복도·계단·미술실 이미지
assets/characters/         강무결·기태하 원본에서 다시 분리한 4방향 3프레임 도트 시트
assets/items/              아이템과 자물쇠 상태 이미지
assets/props/              출석부 이미지
assets/audio/              배경음악과 계단 효과음
게임제작 1.txt             작업 기준 원문
.nojekyll                  GitHub Pages 호환 파일
```

## 제작 범위와 한계

- 이미지가 완성된 단일 배경이기 때문에, 이동·충돌 판정은 배경 위에 수동으로 정의한 좌표와 사각형 영역을 기반으로 합니다. 맵 오브젝트의 픽셀별 정밀 충돌 판정은 아닙니다.
- 소지품은 획득·조회 기능이 구현되어 있으나, 기획서에서 사용을 지정하지 않은 물품에는 임의의 사용 효과를 추가하지 않았습니다.
- 미술실의 최종 대화, 기태하와의 만남, 성공 엔딩은 《게임제작 2.txt》가 제공된 뒤 구현할 예정인 범위로 남겨 두었습니다.
- 원본 지도와 소품 이미지는 웹 로딩에 적합한 WebP 포맷으로 변환하여 넣었습니다. 원본 PNG와 JPG는 해당 사용자가 제공한 자산입니다.

## 이번 수정 사항

- 타이틀 화면을 「돌이킬 수 있을지도 모를 걸음」과 `START` 버튼으로 단순화했습니다.
- 제공된 원본 스프라이트의 각 캐릭터 전신을 기준으로 프레임을 재구축했습니다. 잘못된 자르기·비율을 조정했으며 정지 프레임과 4방향 걷기 애니메이션을 분리했습니다.
- 탐색 선택지가 열린 상태에서 방향키/WASD/모바일 방향키로 자유롭게 이동할 수 있게 수정했습니다.
- 경로 자동 이동을 한 축씩 진행하도록 수정하여 불필요한 대각 점프·스냅을 방지했습니다.
- 브라우저에서 이동, 교실 사물함 자동 접근, 교실 → 복도 → 계단 → 미술실 → 계단 → 복도 맵 전환을 확인했습니다.
